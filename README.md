# Madhur

Engineering student focused on **low-level systems**, **Linux kernel development**, and **compiler engineering**.  
My primary interest lies in understanding and building software that operates close to the hardware.

---

## Areas of Focus

### Low-Level Programming
- C, Assembly (x86), Rust
- Memory layout, calling conventions, linking, and execution model
- Debugging at the binary and instruction level

### Linux Kernel Development
- Kernel modules and device drivers
- Character devices, timers, input subsystems
- DRM/KMS and GPU driver internals
- Reading, modifying, and contributing to upstream kernel code

### Operating Systems
- Bootloader development (BIOS → protected mode)
- Writing a minimal OS kernel
- Interrupt handling, VGA text mode, keyboard input
- Core OS concepts: scheduling, memory management, system calls

### Compiler Engineering
- Lexer, parser, AST construction, semantic analysis
- Syntax-directed definitions and type systems
- LLVM-based compiler development (targeting LLVM IR using Rust)
- Understanding the full compilation pipeline from source to machine code

### Systems Programming
- Linux system programming (POSIX APIs, APUE-style)
- Networking fundamentals (sockets, TCP/UDP) for systems-level completeness
- Reverse engineering and debugging using low-level tools

---

## Learning Approach

- Source-code-first learning (kernel, drivers, compilers)
- Building components from scratch to understand design trade-offs
- Preference for real-world problems over toy examples
- Focus on fundamentals that scale to large systems

I value depth over breadth and correctness over convenience.

## Current Work

- Deepening understanding of Linux kernel internals

- Bootloader and OS kernel development

- Improving ability to navigate and reason about large codebases
